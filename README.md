# Muneeb Azhar — Developer Portfolio

A premium dark portfolio for **Muneeb Azhar**, Senior React Native & Full Stack Developer. Built with React, strict TypeScript, Vite, Tailwind-independent custom CSS, React Three Fiber, Drei, Framer Motion and GSAP-ready architecture. Content prioritizes legibility, accessibility and performance over decorative effects.

## Features

- Responsive, accessible portfolio with project case-study dialogs
- Interactive React Three Fiber engineering core with animated geometry and particles
- Skill matrix, professional timeline, service cards and validated contact form
- Reduced-motion support and lazy-loaded 3D scene
- SEO metadata, favicon, robots.txt and GitHub Pages deployment workflow
- No fabricated project links, GitHub statistics, roles, dates or contact details

## Stack and structure

- **React + TypeScript + Vite** for the application
- **Three.js / React Three Fiber / Drei** for the original abstract core visualization
- **Framer Motion** for reveal, hover and modal transitions
- `src/data/` — projects, skills, experience and services
- `src/components/3d/` — interactive 3D visual system
- `src/lib/config.ts` — name and external contact configuration
- `src/styles/global.css` — responsive visual system and motion preferences
